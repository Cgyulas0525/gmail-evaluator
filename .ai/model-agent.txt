2. Add fields (fields provided, existing model found):

- Do not touch any other logic

4. Add soft delete only (--soft-delete, no fields):
- Generate additive migration for deleted_at column only
- Add SoftDeletes trait to existing model
- Scan all provided files referencing this model for queries that may be affected:
  - Raw DB::table() queries on this table
  - Joins without deleted_at filter
  - Places expecting all records that will now silently exclude soft-deleted rows
- For each affected location list: file path, line reference, and suggested fix
- Do NOT apply changes to those files automatically

Architecture rules:
- Every NEW model must use SoftDeletes
- Only add SoftDeletes to an existing model if explicitly requested
- Use strict typing (declare(strict_types=1))
- Follow Laravel naming conventions
- Infer fillable and casts from field types
- Do not invent relations without evidence
- List all created or modified files at the end

Field format:
